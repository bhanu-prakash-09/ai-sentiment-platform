# AI-Powered Customer Feedback & Sentiment Analytics Platform 📊🚀

An enterprise-grade analytics solution that parses raw customer feedback, translates sentiments through a algorithmic rules engine, and displays data on a modern tracking interface. This project demonstrates a multi-tier architectural layout combining data scripting, secure backend APIs, and web rendering.

---

## 🛠️ Multi-Language Architecture & Tech Stack

- **Data Analytics Engine (Python):** Contains custom token-parsing rules that automate processing raw string arrays to extract customer sentiment polarity scores.
- **Relational Storage Matrix (SQL):** Structured database layout featuring schema constraints, automated auto-increments, and relational tables optimized for indexing text records.
- **Backend Streaming Layer (Java):** High-performance Spring Boot REST API controller mapping structured data models to web-accessible JSON endpoints with active Cross-Origin Resource Sharing (CORS) configurations.
- **Client Presentation Dashboard (HTML/CSS/JS):** A clean interface featuring a flexbox/grid layout, interactive data tables, styled semantic badges, and asynchronous JavaScript fetching architectures.

---

## 📂 Core Folder Structure

- `/python-analytics-engine` : Data engine layer containing text logic processing scripts and raw database schema creation components.
- `/java-backend-api` : Object-oriented enterprise source controllers managing API response routing.
- `/frontend-dashboard` : User interface file containing responsive markup frameworks and tracking grids.
